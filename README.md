# Test Failure Visualization Dashboard

## Overview
A student project for collecting JUnit XML test results from CI builds and visualizing failures across builds and over time to identify recurring problems.

## Planned Features
- Feature 1: upload and parse JUnit XML results.
- Feature 2: recurring failure view with failure-rate trend and top failing tests.

## Tech Stack
- Python
- FastAPI
- SQLite
- pytest
- Single-page frontend with Chart.js
